# Peaceland Notebook - Collectible Handoff

## Put something collectible in a scene, without reading or writing any code

---

## 📋 What this document is for

Adding a "pick it up and it goes in the notebook" object used to mean four manual steps: attach `NotebookCollectTrigger`, drag the note asset into its list, add a collider, add the glow. Miss any one of them and nothing errors — the object just **does nothing when clicked**.

Those four steps are now one window. All you do is:

1. ✅ **Write a note** (fill in a form, no code)
2. ✅ **Sync the database** (one menu click)
3. ✅ **Pick it from a dropdown and press a button**

> **You never need to open a `.cs` file.**
> Everything in this document happens in Unity editor menus.

---

## 🧠 Three things to understand (only three)

| Name | What it is | Where you touch it |
|------|------------|--------------------|
| **Notebook Entry** | One piece of notebook content (title + body + image) | A `.asset` file you fill in through the Inspector |
| **Notebook Database** | The index of every note. The game only sees what is in here | An `.asset`, **synced by menu, never edited by hand** |
| **Collectible** | The object in the scene that unlocks a note when clicked | Generated by the window in this document |

The chain: **write an Entry → sync it into the Database → generate a Collectible in the scene that points at it.**
Break any link and the result is an object that does nothing when clicked.

---

## 🔧 Steps

### **Step 1: Make a note**

```
In the Project window, go to Assets/Notebook/Data
Right click → Create → Peaceland → Notebook → Entry
Name the file, for example NotebookEntry_FloristRose
```

Select it and fill in these fields in the Inspector. **Leave everything else at its default**:

```
NotebookEntryDefinition
┌────────────────────────────────────────────────────┐
│ Entry Id     → globally unique id, e.g. florist-rose│
│                ⚠ never change it later              │
│                  (saves identify notes by this)     │
│                                                     │
│ Section      → which page this note belongs to:     │
│                Directory / Present /                │
│                Memory1 / Memory2 / HiddenStats      │
│                                                     │
│ Title        → the title shown in the notebook      │
│ Body Text    → the note itself (multi-line)         │
│ Image        → the illustration sprite              │
│                ⚠ this is also what the object in    │
│                  the scene will look like           │
└────────────────────────────────────────────────────┘
```

> **It runs with Image empty**, you just get an invisible 1×1 square in the scene. Fine for greyboxing; give real content a real image.

---

### **Step 2: Register it in the database**

```
Menu bar → Peaceland → Notebook → Sync Notebook Database From Assets
```

This scans every Entry in `Assets/Notebook/Data` and writes them into `NotebookDatabase`.

**Do this every time you make a new Entry.** If you forget, the window in step 3 shows a yellow warning and a button that fixes it on the spot — so forgetting is not a problem.

---

### **Step 3: Open the generator window**

```
Menu bar → Peaceland → Notebook → Add Collectible To Scene...
```

It looks like this:

```
Add Collectible
┌──────────────────────────────────────────────────────┐
│ 1. Which note does this unlock?                      │
│    [ Present/florist-rose  —  A Pressed Rose      ▾] │
│                                                       │
│    ⚠ If this note is not in the database yet, a      │
│      yellow warning appears here, with a             │
│      [Sync Notebook Database From Assets] button.    │
│      Press it and the warning goes away.             │
│                                                       │
│ 2. What kind of object?                              │
│    [ World Sprite                                 ▾] │
│                                                       │
│ 3. Options                                           │
│    Pulsing glow        [✓]                           │
│    Hide once collected [✓]                           │
│                                                       │
│            [      Add To Scene      ]                │
└──────────────────────────────────────────────────────┘
```

The dropdown lists **every note in the project**, formatted `section/id — title` and sorted by section, so you never have to go hunting for the file.

---

### **Step 4: Pick a form**

| Option | What it makes | When to use it |
|--------|---------------|----------------|
| **World Sprite** | An image in the world with a collider; click it to collect | The default. Flowers, letters, objects in a scene |
| **UI Button** | A UI image under a Canvas; click it to collect | Buttons on the notebook screen or the HUD |
| **Attach To Selection** | Makes no new object — adds the collect behaviour to whatever you have **selected** | You already placed an art asset and just want it to be pickable |

**Attach To Selection needs a selection in the Hierarchy first.** The button is greyed out until then.

The two toggles:

```
Pulsing glow        → adds a breathing highlight that says "this is clickable"
                      (only works on objects with a SpriteRenderer, not UI Buttons)

Hide once collected → the object hides itself after being collected, so it
                      cannot be clicked twice. Turn it off and collected
                      objects stay in the scene.
```

---

### **Step 5: Press Add To Scene**

You get this in the scene:

```
Collectible - florist-rose
├─ SpriteRenderer          (image = the Entry's Image)
├─ BoxCollider2D           (sized from the image automatically)
├─ NotebookCollectTrigger  (Entries already holds the note you picked)
├─ NotebookCollectableGlowView
└─ Collect Glow            (glow child, made at runtime, invisible in the editor)
```

The object lands **in the middle of your current Scene view**. Drag it where you want it.

The console prints one line to confirm:

```
Collectible ready: 'Collectible - florist-rose' unlocks 'florist-rose'.
```

**Ctrl+Z undoes it** — the new object and the added components are all in the undo group (you may need a few presses).

> With **UI Button**, if the scene has no Canvas the window **makes one** (1920×1080, Screen Space Overlay) and adds a GraphicRaycaster and an EventSystem. Without those two, a UI button does nothing when clicked.

---

## 🎮 What happens at runtime

```
Player clicks the object
   ↓
NotebookCollectTrigger.Collect()
   ↓
Has this Entry already been collected?
   ├─ yes → do nothing
   └─ no  → write it to the save (and show a toast, if the scene has a toast bar)
                 ↓
              hide the object, if Hide once collected is on
```

The scene does **not** need a `NotebookController` placed in advance. If there is one it is used; if not, the collect goes through the global save path instead. Both work.

## 🐛 Common problems

### **1. Clicking does nothing**

Check in this order:

```
① Is this Entry in the NotebookDatabase?
   → Peaceland → Notebook → Sync Notebook Database From Assets

② Was it already collected?
   → the save remembers, so a second click correctly does nothing
   → Peaceland → Save → Reset All Progress, then test again

③ World Sprite: is there a camera? is something covering the collider?
④ UI Button: is there an EventSystem?
   → new scenes get one automatically. For an old scene:
     GameObject → UI → Event System
```

### **2. All I got was a tiny invisible square**

The Entry's **Image field is empty**. Go back to step 1, give it an image, then generate it again (delete the old one).

### **3. The object came out too big or too small**

That is the sprite's **Pixels Per Unit**, not this window. Change the sprite's import settings, or just scale the object in the scene.

### **4. I changed an Entry Id and lost the collected state**

Expected. Saves identify notes by `Entry Id`, so changing it makes a different note. **Once an Entry Id is set, leave it alone.**

### **5. I want one object to unlock several notes**

Generate it, then select it and add to the **Entries** list on its `NotebookCollectTrigger`. It is an ordinary Unity list — drag Entry assets into it.

## 📁 File map

### What you will touch:

| Path | What it is |
|------|------------|
| `Assets/Notebook/Data/*.asset` | The notes you write |
| `Assets/Notebook/Data/NotebookDatabase.asset` | The index (**sync by menu, do not hand edit**) |
| Your own scene | Where generated objects land |

### What you will not:

```
Assets/Notebook/Scripts/     ← all the code, none of it needs reading
Assets/Notebook/Prefabs/     ← the notebook UI itself
Assets/Peaceland/            ← the save system
```

## 🚀 Quick acceptance run

From a new note to collecting it in game, end to end:

```
□ 1. Create → Peaceland → Notebook → Entry
□ 2. Fill in Entry Id / Section / Title / Body Text / Image
□ 3. Peaceland → Notebook → Sync Notebook Database From Assets
□ 4. Peaceland → Notebook → Add Collectible To Scene...
□ 5. Pick it in the dropdown (check there is no yellow warning)
□ 6. Choose World Sprite, press Add To Scene
□ 7. Drag the object into place, Ctrl+S to save the scene
□ 8. Press Play and click it → the console logs the collect, the note appears
□ 9. Click it again → nothing happens (correct, it is already collected)
```

**Zero lines of code** the whole way through.

If what step 6 produced looks wrong, run **Peaceland → Notebook → Harness → Verify Collectible Spawner** first. It generates one of each of the three types in a temporary scene and undoes them again; `[SpawnerHarness] PASS` in the console means the tool itself is fine and the problem is in the Entry or the scene.

## ⚠️ Things not to do

```
✗ Do not hand edit NotebookDatabase.asset  → use Sync; hand edits are overwritten next sync
✗ Do not change a live Entry Id            → saves will not recognise it
✗ Do not edit Assets/Notebook/Scripts/     → ask Yu instead of changing it yourself
```
